Анализ

 

 

Напряжения входа представлены только двумя уровнями с учётом падения напряжения на диодах:

UDint1 = UDint2 = 0,7 В ;

Uint_in_max = VCC = Eип − UDint1 ;

Uint_in_min = VEE = -Eип + UDint2 .

Напряжения выхода ограничены напряжением срабатывания триггера

Uint_out_max = Eип − Uзапас_нелинейных_искажений

Uint_out_min = -Uint_out_max

Напряжение на интеграторе изменяется линейно

Uint_out ( Δt )  = U0 − Uint_in · ΔtC · R ⇒

Uint_in · ΔtC · R = U0 − Uint_out  ( Δt )  ⇒

Δt =  ( U0 − Uint_out  ( Δt )  )  · C · RUint_in .

Напряжение изменяется от U_int_out_min до U_int_out_max и обратно, следовательно

U0 − Uint_out  ( tint_down )  = Uint_out_min − Uint_out_max = -2 · Uint_out_max для Uint_in < 0 ;

U0 − Uint_out  ( tint_up )  = Uint_out_max − Uint_out_min = 2 · Uint_out_max для Uint_in > 0 .

 

Период сигнала c учетом падения на диодах составляет:

T = tint_down + tint_up =

= -2 · Uint_out_max · C · Rint1Uint_in_min + 2 · Uint_out_max · C · Rint2Uint_in_max =

= 2 C · (-Uint_out_max · Rint1Uint_in_min + Uint_out_max · Rint2Uint_in_max) =

= { Uint_in_min = -Uint_in_max } =

= 2 C · (-Uint_out_max · Rint1-Uint_in_max + Uint_out_max · Rint2Uint_in_max) =

= 2 C · Uint_out_maxUint_in_max ·  ( Rint1 + Rint2 )  .

Данная схема позволяет независимо регулировать период сигнала и скважность.
